# 图纸对照与标注工具

## 保留的参考实现

`../assets/drawing-viewer/` 仅保存通用空白模板：

- `blank-template.html/.css/.js`：空白、项目无关的双图层注释器基架；生成器会内联CSS/JS和底图，交付为单个HTML。
- `scripts/build_floorplan_annotator.py`：把同像素宽高的现状图与布置图注入空白模板；省略布置图时，以现状图作为布置图初始副本。必须传入 `prepare_existing_state.py` 生成的执行记录；如采用AI清洗候选，则传入经用户接受、由 `record_cleaned_state_acceptance.py` 生成的绑定记录。生成器核验最终现状图路径、SHA-256、画布尺寸与裁切映射，并将来源链写入页面配置及导出的批注JSON。
- 生成页提供“平面布置图/现状图”切换，以及矩形、圆形、直线、文字、撤销、清空、导入/导出标注JSON；可在图纸上缩放、平移。
- 用户标注按项目ID、图层名和底图SHA-256分开存于当前浏览器；导出的JSON带两图哈希、画布尺寸及现状图源截图哈希/裁切记录摘要，换底图时不应把旧标注坐标直接套用。

将批注解释成空间/功能约束并衔接CAD尺寸与几何JSON时，按 [批注到几何确认流程](annotation-to-geometry-workflow.md) 操作；像素批注本身不带毫米尺度。

示例生成命令：

```sh
cd "${CODEX_HOME:-$HOME/.codex}/skills/xiong-interior-design"
python3 scripts/build_floorplan_annotator.py \
  --project "项目名称" \
  --project-id "project-plan-v1" \
  --existing /绝对路径/现状图.png \
  --existing-state-report /绝对路径/现状图-校验记录.json \
  --output /绝对路径/当前对话workspace/outputs/项目名-平面布局注释器.html
```

先预演检查画布大小与输入哈希；`--execute` 才写入。若已有方案图则附 `--layout /绝对路径/布置图.png`。现状图与布置图必须是同尺寸、同坐标画布的PNG/JPEG/WebP；尺寸相同只是必要条件，生成器不能判断图内要素是否已准确叠合。不同尺寸时不自动拉伸配准，应按可信CAD坐标先校正画布，再人工核对固定要素重合。生成器拒绝覆盖文件，输出自包含，不依赖项目旁置素材或外网库。

生成后的页面可以直接打开。标注存在浏览器本地存储，需交给助手解读时点“导出标注”并附JSON；迭代或换浏览器后可导入JSON继续。导入前会严格核对项目ID、画布尺寸和两张底图SHA-256，底图变化时拒绝旧坐标；如页面已有标注，会先询问是否替换。HTML自身不会把浏览器本地标注自动写回文件。

## 用到新项目时

1. 新项目优先通过生成器，而不是复制已有项目页面。
2. 仅有底图时，生成器会把现状图复制到布置图层作为初始副本，不自行编造设计方案。
3. 黑底或需清洗的现状图应先按截图现状图流程准备。若使用AI候选，需通过参考/候选/叠加图目检、用户确认及绑定记录；生成页面只按最终输入栅格原样显示，不再叠加滤镜或重画工程要素。AI候选的对齐只经人工目检，不等同几何校准。

## 使用与验证

- 点击工具再在图上拖动矩形/圆形/直线；文字工具点击位置输入。再次点击工具退出绘制；浏览状态拖动平移，滚轮缩放，双击适合窗口。
- 两张图分别保存标注；刷新可恢复。用“导出标注”生成可携带JSON。localStorage仅为当前浏览器当前来源存储，换浏览器或来源可能看不到旧标注，不要清除用户数据。
- 已有页面先保留坐标、存储键和用户数据；修改底图/坐标前必须处理旧标注位置关系，不能静默套用。
- 自动回归 `scripts/test_build_floorplan_annotator.py` 覆盖现状图校验记录与PNG哈希/尺寸/裁切映射绑定、同尺寸图生成自包含HTML、未给布置图时复制现状图、尺寸不一致拒绝生成及拒绝覆盖。该测试不模拟浏览器交互。
- 每个新生成页面均须在目标浏览器检查同画布切换与映射、各种标注工具、撤销、清空、JSON导入导出和刷新保留；模板测试通过不代表具体项目页面已验收。
- “导出标注”由页面生成包含项目ID、画布尺寸、两张底图哈希和两层批注的JSON文件；“导入标注”核对这些身份字段后再替换批注。PNG导出不提供。浏览器可能对文件下载/导入弹窗有权限提示，交付前仍须在目标浏览器实际验证。图层切换保留当前缩放与平移，以便在相同视口位置对照。
- 可直接用浏览器打开HTML；自动化工具若禁止file导航，用仅绑定127.0.0.1的本地HTTP服务。不要为此安装新浏览器或绕过工具权限。操作浏览器前遵循用户当前浏览器规范。
